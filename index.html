Cara Upload Kode ke GitHub & Deploy Vercel

Panduan praktis agar website AnimeKu milikmu dapat diakses secara online gratis.

1 Simpan Kode Website

Simpan seluruh kode HTML di atas ke dalam satu berkas dengan nama index.html di komputer/laptop milikmu.

2 Unggah (Upload) ke GitHub

1. Buka GitHub.com dan buat akun gratis.

2. Klik tombol **"New Repository"** (atau tanda + di kanan atas).

3. Beri nama repository, misalnya: animeku-web, pilih Public, lalu klik **Create repository**.

4. Klik opsi **"uploading an existing file"**, lalu drag & drop berkas index.html tadi.

5. Klik **"Commit changes"**.

3 Deploy Gratis ke Vercel

1. Buka Vercel.com dan login menggunakan akun GitHub kamu.

2. Klik tombol **"Add New"** → **"Project"**.

3. Pilih repository animeku-web yang telah dibuat lalu klik **Import**.

4. Pada konfigurasi framework, biarkan default (Other / Static HTML).

5. Klik **Deploy**. Dalam hitungan detik, website AnimeKu milikmu aktif dan siap diakses secara global melalui domain gratis dari Vercel!
